# 产品需求：Astrogate Mail Admin

## 产品定位

一个自托管、开源、面向小团队管理员的邮件系统控制台，用于配置和运维自有邮件域。它不是面向公众的邮箱注册站，也不承诺邮件一定进入 Gmail/QQ 收件箱。

## 用户角色

| 角色 | 能力 |
| --- | --- |
| Owner | 初始化、管理员/会话、全局配置、密钥轮换、备份/恢复及全部授权操作 |
| MailAdmin | 邮件域、邮箱、别名、单封测试邮件、队列和邮件节点维护 |
| DnsAdmin | DNS provider、记录预览/变更/回滚及 DNS 检查 |
| Operator | 查看监控、执行允许的诊断、启动备份，不可读取秘密或执行 DNS 写入 |
| Auditor | 只读查看账户状态、检测结果和审计日志，不看邮件正文/秘密 |
| WebsiteUserAdmin | 可选的网站用户目录管理；权限与 MailAdmin 分开 |

## 页面清单

1. 用户名/密码登录与首次 Setup。
2. 概览仪表盘：服务健康、DNS、TLS、队列、备份、磁盘和待处理告警。
3. 安装与域名向导：域名、MX/A、DNS provider、服务器/IP、端口预检、配置预览。
4. 域名与 DNS：当前记录、期望记录、provider API 或手工模式、diff、dry-run、确认、回滚、传播检查。
5. 邮箱管理：列表/创建/改密/暂停/恢复/配额/别名/转发/延迟删除。
6. 管理员发信：单封支持工单/测试用途邮件、收件人限制、预览、附件限制、发送结果和 Message-ID。
7. 投递与队列：队列数量、状态、近期错误、受控重试/删除；不得显示全文正文。
8. 系统监控：DNS、端口、证书、合成认证、服务、数据库、Agent、磁盘、队列和备份。
9. 备份恢复：计划、目标、加密状态、校验、保留、隔离恢复演练及灾备说明。
10. 系统/节点：导入现有邮件机、Agent 版本、连接状态、组件状态、只读配置扫描和变更计划。
11. 网站用户管理（可选连接器）：只连接显式授权的用户库，查找、验证状态、冻结/解冻、触发重置；不展示密码或验证码。
12. 管理员、角色、会话和审计。

## 首发版本

### P0 必须有

- 密码登录、RBAC、近期密码重认证、审计、配置密钥保护。
- 现有邮件节点只读导入和兼容性检查。
- 邮箱/别名的受限管理 Agent。
- DNS 手动配置清单与检测；一个可验证的官方 API provider adapter。
- 邮件发送测试、队列/错误摘要、TLS/DNS/端口/服务/磁盘/备份监控。
- 加密备份、完整性检查和隔离恢复演练。
- 可部署的 Docker Compose 控制面、systemd Agent、OpenAPI、安装和灾备手册。

### P1 可选

- Astrogate 网站用户数据库连接器。
- 第二/第三 DNS provider 插件、S3 兼容异地备份、Webhook 告警。
- 多邮件节点、多域和组织级委派。
- DKIM 密钥轮换向导及双 selector 过渡。

## 不在首发承诺

- 公开自助注册本域邮箱或无审核群发平台。
- 替代 Roundcube 的完整 IMAP 邮件客户端。
- 自动更改任意注册商或任意 DNS 厂商设置。
- 自动控制 IP 服务商的 PTR、解除 ISP 端口封锁或提升邮件信誉。
- 保证外部邮件进入收件箱，或自动判定 Gmail 垃圾箱原因。
- 默认直接修改用户现有网站生产数据库。

## 关键业务规则

- 网站用户、邮箱账号、后台管理员是三种不同身份。
- 网站用户注册不创建本域邮箱；开通邮箱须显式权限和策略。
- 所有发信必须认证，From 在授权域名内，默认禁止匿名中继。
- 发送状态明确区分本机接受、对方 MX 接受、收件人实际确认。
- DNS 写入只写确认过的目标区域和记录；保留网站 A，变更前展示 diff。
