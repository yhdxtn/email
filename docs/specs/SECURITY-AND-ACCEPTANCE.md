# 安全基线、监控状态和验收

## 安全基线

- HTTPS only、安全 Cookie、HSTS（确认 HTTPS 全链正常后启用）、CSRF 防护、CSP、输入校验、输出编码、依赖扫描和速率限制。
- 首次初始化只允许一次；管理员设强密码直接登录；高风险操作重新输入密码；所有角色默认拒绝、按动作授权。部署需使用 HTTPS 和来源 IP 限制以补偿单因素登录。
- 高风险操作重新认证并二次确认；后台写入不可篡改/追加式审计。
- 用户、邮箱、管理员目录独立；密码使用适当的密码哈希。SMTP/DNS/Agent 私钥由独立 secret store 加密管理，永不回显。
- 控制面与 Agent 使用双向身份校验、短期签名任务、重放保护、幂等 ID、时间限制和操作 allowlist。
- 不允许任意 shell、远程文件读取、任意 SQL、动态 Ansible 文本、任意服务名、参数拼接或公网 webhook 任意 URL。
- 审计和日志屏蔽密码、验证码、Token、邮件正文、附件、私钥和完整凭据；错误仅展示安全的 request id。
- DNS 写、队列删除、恢复、用户删除、密钥轮换必须生成计划、显示影响并要求二次确认；有快照和幂等保护。
- 测试发信必须有授权收件人；限制频率/容量/附件；拒绝未认证中继和未授权 From。
- 备份加密，密钥分离，恢复时验证来源/版本/完整性并先在隔离环境演练。

## 监控项目与状态语义

| 检查 | 成功表示 | 不代表 |
| --- | --- | --- |
| DNS A/MX/TXT | 公开解析得到期望记录 | 收件箱投递成功 |
| TCP 25/587/993 | 指定源可以建立 TCP 连接 | TLS、登录或邮件业务成功 |
| STARTTLS/证书 | 域名、链、有效期和协商满足要求 | 对方信任域名或 IP 声誉良好 |
| SMTP submit 250 | 本机 SMTP 接受投递请求 | 对方服务器/收件箱已收到 |
| 对方 MX 2xx | 收件方邮件服务器接受 | 进入主收件箱（可能在垃圾箱） |
| IMAP 合成登录 | 测试账户按约定成功登录 | 所有邮箱/网页功能均正常 |
| DKIM 签名/公开 key | 本机签名且 DNS 公钥匹配 | 外部已对真实邮件验签通过 |
| 外部人工确认 | 指定外部邮箱用户实际看到/回复 | 所有收件服务都可投递 |
| PTR | IP 反向解析及可选前向匹配 | IP reputation 或邮件送达保证 |

探测需记录执行时间、数据来源、耗时、状态和脱敏错误。服务状态分 `healthy`, `degraded`, `failed`, `unknown`；未知/过期结果不能显示绿色。端口探测通过而 SMTP/证书失败时，页面必须分别展示。

## 威胁场景

1. 管理员网页参数被注入 shell：Agent 固定 RPC、无任意命令能力、参数结构验证。
2. DNS Token 泄露：最小权限、加密储存、页面不回显、轮换和审计。
3. 控制面被滥用发垃圾邮件：仅认证管理员、限速/配额、From 限制、测试收件人确认、默认阻断群发。
4. 恶意 DNS 目标触发 SSRF：阻止私网/metadata 地址，DNS adapter 使用固定 provider endpoint allowlist。
5. 备份被盗或恶意恢复覆盖新邮件：客户端加密、签名/完整性校验、版本门槛、隔离演练、回滚前快照。
6. 未授权管理员改邮箱/域：近期密码重认证、RBAC、二次确认、追加式审计、可撤销会话；管理入口使用 HTTPS 与来源 IP 限制。
7. 监控错误显示“送达成功”：每阶段单独状态，注明证据和最后检查时间。

## 验收检查清单

### 功能

- [ ] 全新环境可部署，首次 Owner 初始化只执行一次，用户名/密码可直接登录，敏感操作需近期重新输入密码。
- [ ] 邮箱新建/改密/停用/恢复/别名经过 Agent，且不将密码或哈希返回前端。
- [ ] 网站用户操作和邮箱账号管理分别授权、分别审计；禁用网站用户连接器时相关页面不可操作。
- [ ] 管理员发送单封测试邮件有限制、可查 Message-ID/状态、正文不落审计日志。
- [ ] DNS 手工模式生成准确记录；API 模式展示 dry-run、需授权确认、可回滚。
- [ ] 网站 A 记录保护；MX、邮件 A、SPF、DKIM、DMARC、PTR 分项检查。
- [ ] 监控能区分服务、DNS、端口、TLS、IMAP、队列、磁盘、备份和 Agent 状态。
- [ ] 备份包含 Maildir 与配置/DB，能加密校验；隔离恢复不会改生产服务。

### 安全负向测试

- [ ] 未认证/无权限 API 返回 401/403；不可通过直接请求绕过前端权限。
- [ ] Shell 元字符、路径穿越、任意 hostname/URL、任意服务名均被拒绝。
- [ ] 恶意 API Token 不回显；登录/错误响应不泄漏堆栈、密码、私钥、邮件正文。
- [ ] 重放任务签名/过期任务/重复幂等键不会产生重复操作。
- [ ] DNS 缺少授权、provider 不支持、API 超时时不会悄悄写入其他 DNS 区域。
- [ ] 无认证邮件中继被拒绝；未经授权收件人/From/频率超限被拒绝。
- [ ] 恢复包损坏、签名错误或目标节点版本不兼容时停止恢复。

### 发布准备

- [ ] 格式化、静态分析、单测、集成测试、API 安全测试和 Docker build 全通过。
- [ ] 从空卷启动部署通过；升级和数据库迁移有备份与回滚步骤。
- [ ] 安装/管理员/DNS/邮件节点/备份与灾备手册已按干净机器实际执行。
- [ ] 容器和仓库无秘密；依赖有锁定版本和许可证；公开开源许可证明确。
- [ ] 文档明确写出 Gmail 垃圾箱、PTR、外部回信和服务商 API 限制等未完成事实。
