# 管理员操作手册

## 身份和权限

Owner 管理全部已实现功能；MailAdmin 管理域/邮箱/受限邮件；DnsAdmin 管理 DNS；Operator 负责探测、备份及站内告警；Auditor 只读审计/诊断。保留 WebsiteUserAdmin 角色但网站连接器未实现。邮箱账号、管理员账号与网站注册用户是不同实体；不会随网站注册自动创建邮箱。

管理员使用用户名和密码直接登录，登录会话最长 8 小时。管理员密码至少 9 个字符、UTF-8 长度不超过 72 字节；邮箱账户密码仍要求至少 14 个字符。高风险操作需要在最近 5 分钟内重新输入管理员密码，并按页面确认具体变更；这不再要求 TOTP。单因素登录与较短密码会降低后台账户保护强度，应只通过 HTTPS 访问，并建议使用 `ADMIN_SOURCE_IPS` 限制来源。管理员改角色或停用会吊销已有会话；不允许停用最后一个可用 Owner。当前没有管理员密码自助重置流程，投产前应确定受控的离线恢复流程，不能用公开“万能口令”。

## 页面顺序

建议先设置组织/时区，注册只读节点并扫描，再配置邮件域、核对实际 NS 与手工 DNS 模板，之后验证 SMTP。现有邮箱只读导入只保存账号元数据，不读回密码哈希。写入接管必须经过克隆机验收。

创建/停用/恢复/改密/配额提交后进入任务队列；页面中 queued/running 不等于节点完成。只有确认结果才把邮箱标为已生效。对 unknown 任务先只读核查节点，不要换一个幂等键重复发送同一操作。首次任务因外部失败未创建时可能显示 failed；也应以节点读取结果为准再处理。

软删除保留 Maildir，并通过单独预览/再次确认；没有自动永久清理作业。账户恢复不应覆盖原有邮件目录。别名仅支持受控的一跳目标，外域转发还需部署端 allowlist。邮箱配额使用量和最后登录信息不可用时显示未采集，不显示假 0。

## DNS

手工模式可以生成和复制记录，修改仍在真正的 DNS 托管商处进行。注册商名称与 DNS provider 独立保存。自动模式只有 Cloudflare 适配代码，配置 Zone 与最小权限 token 后仍需验证实际权威 NS。修改先生成 before/after/diff，输入确认语句后提交；若计划生成后外部记录变化，会拒绝覆盖。回滚也是新的高风险操作，不承诺无条件覆盖外部管理员的后续修改。

## 测试邮件

只发单封到部署允许的明确测试收件人。填写发件人、收件人、主题和正文；可预览纯文本或经过清理的 HTML，有限附件也受服务端限制。重新认证并确认后返回任务 ID。不要在截图/审计导出中保存正文或附件。

SMTP 已接受仅代表提交服务器接收；人工确认、对方服务器接受、最终收件箱到达是不同事实。需自己在收件账户查看并回信再记录观察项。本版未解析完整 DSN/退信与跨服务商声誉。

## 审计和诊断

首页显示真实数据库/任务/节点状态。节点未连接时是离线或未配置；缺少遥测时显示未知。审计表是追加式；网页导出仅导出当前页，并非全库。时间以页面本地格式展示，操作数据保存数据库时间；组织时区不是远端邮件服务配置更改器。

告警当前仅站内去重/静默/恢复状态。设置告警邮箱不代表开启邮件通知；Webhook 也未实现。网站用户页面明确关闭，不会擅自连接或修改真实网站数据库。
