# 威胁模型与剩余风险

资产：管理员身份、SMTP/DNS 凭据、邮箱认证哈希、邮件与附件、节点文件、DKIM/TLS 私钥、备份和审计。边界：浏览器→HTTPS边缘→控制面→PostgreSQL；控制面→mTLS/签名Agent；控制面→固定Cloudflare API和配置的SMTP服务器。

| 威胁 | 已实现控制 | 剩余风险/未验收项 |
|---|---|---|
| 匿名控制后台/跨站操作 | 一次性 setup、独立账户、密码限速、近期密码重认证、CSRF、同站Cookie、Origin校验、RBAC | 管理员为密码单因素登录，账户保护低于 MFA；完整生产安全验收与密码恢复流程未完成 |
| 任意 shell/文件路径/SQL | 固定 RPC 和 schema、部署路径白名单、固定 argv、参数化 SQL | root helper 尚未实机执行；代码复核不能替代渗透测试 |
| Agent 冒充/重放 | mTLS、客户端证书指纹、实例ID、60秒签名、nonce账本、参数指纹 | CA轮换、账本容量和时钟误差需运维；Java连接链尚未联调 |
| 重复修改/超时后误报 | 持久幂等键、未知结果、不自动重发、计划和审计 | DB/外部副作用不存在跨系统原子事务；需人工核对 |
| DNS误覆盖网站 | 管理记录限定、快照比较、二次确认、漂移拒绝、回滚 | 真实 provider 合约与 Zone 验收未完成 |
| 发信滥用/数据泄漏 | 单收件人allowlist、发件域限制、配额、附件限制、日志不存正文 | 未做恶意附件完整扫描、外部 SMTP 验收或内容审计 |
| 备份篡改/路径穿越 | AES-GCM、认证后提取、manifest哈希、拒绝链接/穿越、隔离目录 | 文件集合不是全栈快照；S3/完整DB恢复未实现 |
| SSRF | 无任意网页URL/Webhook接口；Agent/SMTP目标仅部署配置；Cloudflare URL固定 | 控制面管理员/部署者仍是高信任边界；DNS外发查询不是通用HTTP |
| 审计擦除 | 应用账户无审计修改/删除权限，数据库触发器拒绝 | 数据库超级管理员仍能改变数据库；未部署外部不可篡改存储 |

Secret 字段 AES-256-GCM 加密并用用途标识绑定；明文输入不回显，测试生成的密钥仅在临时目录。此加密不能抵御已经控制后端进程且能读取 master key 的攻击者。

当前后端启动进程能读取 Flyway 迁移凭据，所以虽然 SQL 运行账户与迁移账户区分，不能宣称对后端远程代码执行形成绝对数据库隔离。更严格的生产形态应把迁移独立为一次性 Job 并撤掉后端运行阶段的迁移秘密，随后验证 Flyway 权限与升级路径；本次未完成该改造。

源码扫描只有若干确定性模式，输出零发现不等于不存在所有秘密/漏洞。尚未进行完整依赖CVE扫描、SAST、恶意HTML/附件全面验证、浏览器无障碍审计、负载测试或第三方安全审计。所有未确认的状态须保持 unknown/blocked，而不是绿色健康。
